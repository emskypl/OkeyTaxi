# 🚕 OkeyTaxi

A clean, responsive, single-page website layout for a taxi service built with pure HTML5 and CSS3.

## ✨ Features

- **Pure HTML & CSS:** Lightweight with zero external dependencies or JS frameworks.
- **Responsive Layout:** Adapts smoothly across mobile, tablet, and desktop screens.
- **Fast Loading:** Simple, optimized code structure for instant page loads.
